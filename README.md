# Raven Shield C++
Source reconstruction of Rainbow Six 3: Raven Shield, performed using
[Ghidra](https://github.com/nationalsecurityagency/ghidra) and [UELib](https://github.com/EliotVU/Unreal-Library).

This is not the game's original source code. This is new code which produces compatible binary artifacts.

## Details
- Game Version: 1.60
- UE2 Build: 927
- C++ Version: C++17
- Formatting/Linting Standard: Clang LLVM
